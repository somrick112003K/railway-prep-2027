RAILWAY PREP 2027 — INSTALLATION

Contents:
- index.html: app interface and study tools
- manifest.webmanifest: installable app metadata
- sw.js: offline cache service worker
- icon.svg: app icon

IMPORTANT:
This is a Progressive Web App (PWA). For iPhone Home Screen installation and offline caching,
the files must be hosted on an HTTPS website. Opening index.html directly from Files will let
you preview the app, but will not enable full PWA installation/offline service-worker support.

Suggested no-cost hosting:
1. Create a GitHub account and a new public repository.
2. Upload all four files to the repository root.
3. In repository Settings > Pages, select Deploy from a branch, choose main and /(root).
4. Wait for GitHub Pages to provide the HTTPS website address.
5. Open that address in Safari on your iPhone.
6. Tap Share > Add to Home Screen > Add.
7. Open the installed app once while online. It will then cache the app shell for offline use.

Progress and notes are stored locally in the browser/device. They do not sync across devices.
The app is an independent study companion, not an official RRB application.
Check the latest official RRB notice for the current exam pattern, dates, eligibility and typing requirements.
